How to play

Use your arrow keys or WASD keys to move the tiles. When two tiles with the same number collide, they merge into one with double the value.

After each move, a new tile will appear in a random empty cell. Create the 2048 tile to win. If there are no possible moves, the game is over.

On touch devices, swipe in any direction to move the tiles.
